# aeromro-agentic-copilot
Agentic copilot for aircraft engine maintenance: multi-agent system (LangGraph) with MCP tools, A2A agent-to-agent communication and AG-UI streaming interface, deployed on AWS (Bedrock, Lambda). Predictive maintenance on NASA C-MAPSS + RAG over FAA regulatory documents, with evaluation, guardrails and cost/latency tracking.
